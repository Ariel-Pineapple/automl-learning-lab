# AutoML Learning Lab

A hands-on learning lab for Machine Learning and AutoML, from fundamentals to optimization, MLOps, and AWS.

**By Luis Ariel Vázquez Piña**

## About this repository

This repository documents my learning journey from the foundations of Machine Learning to Automated Machine Learning.

The goal is not only to study concepts, but to understand them through practical experiments, notebooks, comparisons, and small projects.

Over time, this repository will include topics such as:

* Machine Learning fundamentals
* Data preprocessing and feature engineering
* Model evaluation
* Cross-validation
* Hyperparameter optimization
* Machine Learning pipelines
* Automated Machine Learning
* Bayesian optimization
* Meta-learning
* Ensemble methods
* AutoML frameworks
* MLOps
* AWS Machine Learning services
* Cloud-based AutoML
* End-to-end AutoML projects

## Learning Approach

Each topic will try to follow the same structure:

```text
topic/
│
├── README.md
├── notes.md
├── experiment.ipynb
└── images/
```

### README.md

Short explanation of the concept, why it matters, and how it connects with AutoML.

### notes.md

Personal study notes, definitions, observations, and key ideas.

### experiment.ipynb

A practical experiment demonstrating the concept with Python.

## Capstone Project

The long-term goal of this repository is to build a small educational AutoML system capable of:

```text
Dataset
   ↓
Data Analysis
   ↓
Preprocessing Search Space
   ↓
Model Search Space
   ↓
Hyperparameter Optimization
   ↓
Cross-Validation
   ↓
Model Ranking
   ↓
Best Pipeline
```

The system will progressively incorporate ideas studied throughout the repository.

Potential components include:

* Automatic task detection
* Data preprocessing
* Model selection
* Hyperparameter optimization
* Cross-validation
* Experiment tracking
* Model leaderboard
* Best model selection
* Model persistence
* API deployment
* Cloud deployment
